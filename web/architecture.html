🎯 Problema

Las comunidades nativas de Satipo enfrentan limitaciones críticas:

  • Sin conectividad convencional (no hay WiFi ni 4G)
  • Energía limitada (sin línea eléctrica)
  • Geografía compleja (terreno accidentado)
  • Cambios climáticos que aumentan riesgo de incendios forestales

💡 Solución

Alerta Satipo es un sistema de detección temprana de incendios que combina:

  • Edge AI: Procesamiento inteligente en el borde (sin depender de cloud)
  • LoRaWAN: Comunicación de baja energía y largo alcance
  • Energía solar: Autonomía 8-12 meses sin línea eléctrica
  • Interfaces dual: App móvil + Dashboard web

🏗️ Capas de la arquitectura

1. Capa de sensores (Edge - Hardware)

  • ESP32: Microcontrolador principal con LoRaWAN integrado
  • Sensores:
    • Temperatura (DS18B20)
    • Humo / Calor (MQ-2, MQ-7)
    • Humedad (DHT22)
    • Dirección y velocidad de viento
  • Energía: Panel solar + batería LiFePO4 + regulador MPPT (autonomía 8-12 meses)

2. Capa de procesamiento (Edge AI)

  • Raspberry Pi 4: Gateway LoRaWAN + servidor local
  • TinyML: Modelo de inferencia ligero (<50MB) que detecta patrones anómalos
  • Decisión inteligente: No es solo "humo = fuego", sino análisis multimodal:
    • Temperatura + humedad + velocidad de viento
    • Historial de patrones normales vs anómalos
    • Filtrado automático de falsos positivos
  • Latencia: Decisión en <500ms sin depender de conexión remota

3. Capa de conectividad (LoRaWAN + Fallback)

  • LoRaWAN: Comunica nodos ESP32 con gateway (10-15km de alcance)
  • Ventajas:
    • Muy baja energía (batería dura 6-12 meses)
    • No requiere WiFi ni 4G
    • Costo operativo mínimo
  • Fallback satelital: Datos se guardan localmente y se sincronizan cuando hay conexión

4. Capa de aplicación (User Interface)

  • App móvil: Para pobladores
    • Alertas en tiempo real
    • Reportes comunitarios
    • Mapa de sensores
    • Contacto con autoridades
  • Dashboard web: Para operadores/administradores
    • Estado de nodos en tiempo real
    • Monitoreo de batería y energía
    • Historial de alertas
    • Planificación de mantenimiento

🔄 Flujo de datos

ESP32 (Sensores) → LoRaWAN → Raspberry Pi (Edge AI) → Decisión local → App Móvil / Dashboard

⚡ Ventajas del modelo

  • Independencia energética: Solar + batería (funciona 24/7 sin línea eléctrica)
  • Autonomía de conectividad: Detecta incendios incluso sin internet central
  • Bajo costo: Hardware accesible, sin suscripciones cloud
  • Latencia cero: Decisiones instantáneas en el borde
  • Escalable: Agregar nodos es desplegar un ESP32
  • Resiliencia: Funciona en degradación de conectividad

📊 Modelo de detección (Edge AI)

El algoritmo evalúa múltiples variables:

  • Temperatura: Incremento >5°C en 5 minutos = alerta
  • Humo: Concentración >60 ppm = sospecha
  • Correlación: Temp + Humo + Baja humedad + Viento = Riesgo Alto
  • Contexto temporal: Patrones anormales se validan en 15 minutos
  • Histórico: Se compara con baseline mensual de la zona
  • Precisión esperada: >94% en detección (falsos positivos <6%)

🛠️ Stack Técnico

Capa Tecnología Función
Sensores ESP32 + DHT22, MQ-2, DS18B20 Captura de datos ambientales
Comunicación LoRaWAN (LORA32 SX1278) Transmisión baja energía, largo alcance
Procesamiento Raspberry Pi 4 + TensorFlow Lite Inferencia de Edge AI
Backend Node.js / Python API y almacenamiento local
Frontend HTML5/CSS3/JavaScript (responsive) UI móvil (app) y web (dashboard)

📈 Métricas de desempeño esperadas

  • Precisión: >94% en detección (falsos positivos <6%)
  • Latencia: <2 segundos de sensor a alerta
  • Disponibilidad: 99.2% (solo mantenimiento programado)
  • Autonomía: 8-12 meses sin recarga solar (modo bajo consumo)
  • Cobertura: 12-15 km de radio LoRaWAN desde gateway
  • Escalabilidad: Hasta 100+ nodos por gateway

🚀 Diferenciador del proyecto

Alerta Satipo no es un simple "app de alertas". Es una solución completa de Edge Computing + TinyML + LoRaWAN que empodera a comunidades remotas con tecnología de punta, sin dependencia de infraestructura costosa o conectividad centralizada. Es una demostración práctica de cómo la IA descentralizada puede salvar vidas en zonas sin acceso a tecnología convencional.
